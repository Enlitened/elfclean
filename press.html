In one line

ElfClean is a Mac app that finds the disk space AI tools and code leave behind, and won't delete work you haven't pushed.

In one paragraph

Coding agents, local AI models and every project an AI helped build quietly fill a Mac's disk: node_modules in old projects, agent worktrees and transcripts, Ollama and Hugging Face models, Xcode builds and package caches. ElfClean finds that space, explains each item in plain language and moves nothing until you've reviewed it. It reads each project's Git repository, so work that isn't committed or pushed anywhere is marked At risk and never ticked for you. Everything goes to the Trash, and History can put it back. Scanning is free; one purchase unlocks cleaning everything at once, with no subscription, account or telemetry.

What's unusual about it

  • It reads Git. Every project shows whether it has changes that aren't committed or pushed anywhere, and that's checked again just before anything is removed.
  • It knows AI tools. Models that share files are counted once, conversation history is archived rather than treated as a cache, and the worktrees agents make are listed with their repositories.
  • It's careful by default. Each item says what it is, what changes if it goes and how to get it back. Items go to the Trash, and History can put them back.
  • It's honest about numbers. Measured sizes only: no health score and no claim that cleaning speeds up a Mac.
  • One person, tested hard. The current version has more than 1,100 automated package tests and 500 app tests, and every section was reviewed by independent audits that had to prove each bug with a failing test before it was fixed.
